# Student Marks Calculator

A simple C++ program that takes a student's name and three marks, then calculates and displays the total and average.

## Features
- Enter the student's name.
- Enter three marks.
- Calculate the total marks.
- Calculate the average marks.
- Display the results.

## Technologies & Concepts
- C++
- Input / Output
- Variables
- Strings
- Arithmetic Operations

## Purpose
This project was created as part of my programming learning journey to practice basic C++ concepts.
