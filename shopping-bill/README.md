# Shopping Bill Calculator

A simple C++ program that calculates a shopping bill based on product price and quantity, and applies a discount when the total exceeds 50.

## Features
- Enter the product price.
- Enter the product quantity.
- Calculate the total before discount.
- Apply a 25% discount if the total exceeds 50.
- Display the final total after discount.
- Check for negative input values.

## Technologies & Concepts
- C++
- Input / Output
- Variables
- Conditional Statements (if / else)
- Arithmetic Operations
- `iomanip` and `setprecision`

## Purpose
This project was created as part of my programming learning journey to practice basic C++ concepts and conditional statements.
